# Price Tracker - Beyerdynamic

מערכת מעקב מחירים עבור מוצרי Beyerdynamic בישראל. המערכת מאפשרת לייבא רשימת מוצרים מקובץ CSV, לחפש מחירים אצל ספקים שונים בישראל, ולזהות ספקים שמוכרים מתחת לסף מחיר מוגדר.

## תכונות

- 📁 **ייבוא מוצרים מ-CSV** - תמיכה בקבצי CSV עם עמודות בעברית
- 🔍 **חיפוש מחירים אוטומטי** - שלוש אפשרויות לחיפוש מחירים:
  - **Google Search (SerpAPI)** - חיפוש מקיף ב-Google Shopping ישראל
  - **Zap.co.il** - סריקת אתר השוואת המחירים הישראלי
  - **ייבוא ידני** - ייבוא מחירים מקובץ CSV
- ⚠️ **זיהוי חריגים** - סימון ספקים שמוכרים מתחת לסף מוגדר
- 📊 **לוח בקרה מודרני** - ממשק משתמש מעוצב עם תמיכה בעברית
- 📤 **ייצוא לדוח** - ייצוא רשימת הספקים החריגים ל-CSV

## התקנה

```bash
# Clone או התקנה
cd price-tracker

# התקנת dependencies
npm install

# הגדרת משתני סביבה
cp .env.example .env.local
# ערוך את .env.local והוסף את ה-API key שלך

# הפעלה
npm run dev
```

פתח [http://localhost:3000](http://localhost:3000) בדפדפן.

## מקורות מחירים

### Plan A: SerpAPI (Google Search)
- **יתרונות**: תוצאות מקיפות, מוצא את כל הספקים
- **חסרונות**: דורש API key (100 חיפושים חינם לבדיקה)
- [הרשמה ל-SerpAPI](https://serpapi.com)

### Plan B: Zap.co.il
- **יתרונות**: חינם, ממוקד בישראל
- **חסרונות**: דורש web scraping, עלול להפסיק לעבוד אם האתר משתנה

### Plan C: ייבוא ידני
- **יתרונות**: תמיד עובד, שליטה מלאה
- **חסרונות**: דורש עבודה ידנית

## מבנה הקובץ CSV

קובץ המוצרים צריך להכיל את העמודות הבאות (בעברית):

| עמודה | תיאור |
|-------|-------|
| שם פריט / לינק | שם המוצר |
| מק"ט יצרן | מק"ט יצרן |
| ברקוד | ברקוד המוצר |
| מחיר מומלץ לצרכן בש"ח כולל מעמ | מחיר מומלץ |

## שימוש

1. **ייבא מוצרים** - לחץ על "ייבוא CSV" וגרור את קובץ המוצרים
2. **הגדר סף** - השתמש בסליידר להגדרת אחוז הסף לזיהוי חריגים
3. **בחר מקור** - בחר את מקור המחירים (SerpAPI/Zap/ידני)
4. **בדוק מחירים** - לחץ על "בדוק הכל" או על "בדוק מחירים" ליד כל מוצר
5. **צפה בתוצאות** - לחץ על מוצר לצפייה בפרטי הספקים והמחירים
6. **ייצא חריגים** - לחץ על "ייצא חריגים" להורדת דוח CSV
